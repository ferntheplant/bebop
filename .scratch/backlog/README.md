# Backlog

Untriaged. Anything noticed and not yet placed: vague feature requests, bug reports, nagging doubts.

Dump freely — one file per item, named by slug, never a number. A title and a couple of sentences is enough; if
it needs more, it is already sharp enough to be a ticket. A bug report should carry a high-level repro wherever
one is possible.

Being in this directory _is_ the status, so items need no frontmatter at all. Triage is the move out — see
[the tracker doc](../../.agents/ISSUE-TRACKER.md#triage).

This is the fog you tripped over. The fog you are walking _toward_ belongs in a map's **Not yet specified**.
