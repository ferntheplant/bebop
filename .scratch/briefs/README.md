# Standalone briefs

Work scoped enough to start a bounty on, belonging to no larger effort. Most bug fixes and small features live
here.

A brief that came out of an effort's map lives under that effort's `briefs/` directory instead.

Every brief carries a `Status:` line and a mandatory **Done when** section — the proto-acceptance-criteria a
spec is later distilled from. Format: [the tracker doc](../../.agents/ISSUE-TRACKER.md#file-formats).
