# Standalone issues

Decisions that need grilling, research, or a prototype to settle, and belong to no larger destination.

An issue that belongs to an effort lives under that effort's `issues/` directory instead. One that would need a
map of its own is an effort — but that needs a destination you can name _and_ at least two things you can't yet
specify.

Format and lifecycle: [the tracker doc](../../.agents/ISSUE-TRACKER.md#file-formats).
