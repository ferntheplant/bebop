# Unprojected tickets

Triaged work belonging to no project — no map claims it, and none needs to.

A ticket that belongs to a project lives under that project's `tickets/` directory instead. Both kinds use the
same format; only the directory differs. Format and lifecycle:
[the tracker doc](../../.agents/ISSUE-TRACKER.md#file-formats).

Two things reliably land here: tooling for the tracker itself, and repo-wide hygiene decisions no destination
owns. If several arrive with a shared destination between them, that is when to ask whether they are a project.
